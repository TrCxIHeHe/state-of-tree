# Governance Tree

Sarkaro Rakshathi Kendra — Website Design & Development Brief

Build a polished, modern, responsive static website for Sarkaro Rakshathi Kendra (R.), based on the reference images I am uploading with this prompt.

The uploaded images are the primary visual and content references for the organization. Study them carefully before designing the site.

1. Core Design Concept

The most important visual concept in this website is the half-living, half-dried tree shown in the reference material.

This tree must become the dominant visual metaphor and primary visual element of the website.

The tree represents the contrast between:

a healthy, functioning society/governance system

deterioration, corruption, non-professionalism and systemic problems

The website should visually communicate this idea before the user even reads the text.

IMPORTANT

Do NOT treat the tree as a small decorative image.

Do NOT place it somewhere near the bottom of the page.

Do NOT make the website look like a digital recreation of the uploaded pamphlets.

Instead, reinterpret the material into a modern editorial / institutional website, with the tree acting as the central visual identity.

The overall feeling should be:

serious + intellectual + institutional + thought-provoking + modern + Indian

It should feel closer to a governance think tank / civic institution / public policy organization than a conventional NGO website.

2. Hero Section — Tree Must Dominate

Create a visually powerful hero section.

The hero should immediately establish the organization's philosophy.

Use the uploaded half-green / half-dried tree image as the primary visual asset if possible.

The tree should occupy a large portion of the hero viewport, approximately 55–70% of the visual composition.

Use a spacious, premium composition rather than a crowded layout.

Possible conceptual hierarchy:

SARKARO RAKSHATHI KENDRA

ಸರ್ಕಾರೋ ರಕ್ಷತಿ ಕೇಂದ್ರ

Then the major conceptual statement:

GOVERNANCE

followed by the idea from the reference:

A nation is like a tree.
Governance is its root.

The tree should visually reinforce this statement.

Tree interaction

If technically appropriate, use very subtle animation:

gentle parallax movement

extremely subtle leaf movement

slow atmospheric movement

subtle reveal when entering the viewport

Do NOT make it look like a game or flashy marketing website.

The animation should feel sophisticated and almost cinematic.

The dried side should remain visually distinct from the healthy side.

3. Visual Storytelling

The tree should not disappear from the conceptual narrative after the hero.

Use the tree metaphor throughout the website.

4. Kannada Is First-Class Content

The uploaded references contain substantial Kannada text.

This Kannada content is important.

Rules:

Preserve Kannada Unicode correctly.

Do NOT transliterate Kannada into English.

Do NOT automatically translate Kannada and replace the original.

Do NOT invent Kannada text.

Do NOT rewrite the supplied Kannada unless explicitly instructed.

Preserve the meaning and wording of the supplied source material.

Use a proper Kannada-compatible web font.

Use a high-quality font such as:

Noto Sans Kannada

or another excellent Unicode Kannada font.

Kannada should look intentional and premium, not like fallback browser text.

Where appropriate, use:

Kannada as the primary heading

with English as supporting/explanatory text.

The website should comfortably support mixed:

ಕನ್ನಡ + English

content.
