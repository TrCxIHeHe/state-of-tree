# Sarkaro Rakshathi Kendra

Website for Sarkaro Rakshathi Kendra (R.) — a watchdog of government advocating professionalism in administration. Built around the organization's central metaphor: a nation is like a tree, and governance is its root.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React + TanStack Router, SSR)
- Tailwind CSS v4
- TypeScript

## Development

Requires Node.js.

```sh
npm install
npm run dev
```

Other scripts:

```sh
npm run build      # production build
npm run preview    # preview the production build
npm run lint        # eslint
npm run format      # prettier
```
